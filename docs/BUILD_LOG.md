## 2026-11-08 — Runs tab: live training telemetry

- Added a W&B-style **Runs** tab. Run state lives in three new tables (`runs`, `run_points`, `run_metrics`), created with `IF NOT EXISTS`; no existing table changed. Deleting an experiment unlinks its runs. Exports include runs and points.
- Ingest is one event stream (`start`, `log`, `config`, `summary`, `heartbeat`, `finish`) over `POST /api/runs`, MCP `log_run_events`, or a JSONL file (`import_run_file`). It is idempotent: points upsert on (run, metric, step), and config, summary and meta merge. NaN/Inf are stored as NULL and counted. Per-metric stats update incrementally on append and are recounted otherwise.
- Reads: run list with auto summary (last value per training metric), status `stalled` after 5 minutes of silence, and series downsampled to equal step buckets (mean plus min/max band).
- UI: list with status, group and text filters and key-metric columns; a run page with a pre-built dashboard (Loss / Metrics / Optimization / System, train/val merged), step or relative-time axis, smoothing, log scale, chart filter, a NaN/Inf warning, metric, config, summary and system tables, and delete with confirm. Compare overlays runs and shows config differences. The experiment page lists linked runs.
- Python client `clients/python/parallax_track.py`, stdlib only: a background flush every 2 s, a write-ahead JSONL log, auto/online/offline modes, retry without blocking, nvidia-smi and /proc system metrics every 15 s, git, Slurm and GPU meta, exit status via atexit and excepthook, and `sync` for files or a streamed stdin (`ssh … tail -F | sync -`).
- MCP: 6 new tools (33 in total).
- Verification run: 6 new store/dashboard tests and the extended MCP stdio test passed. 41 of the 43 other tests passed; `http.test.ts` and `workspaces.test.ts` fail under the Node type-stripping loader, which cannot resolve `next/server`.
